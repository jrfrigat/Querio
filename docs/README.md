# Querio documentation

The guides live here in English (`en/`) and Russian (`ru/`), kept in step with each other. The API
reference is generated from the XML documentation in the source and is not stored in the repository -
`docfx docfx.json` builds it, and `.github/workflows/docs.yml` publishes the site to GitHub Pages.

Start with [getting started](en/getting-started.md), then [architecture](en/architecture.md) for why
the model is shaped the way it is.
